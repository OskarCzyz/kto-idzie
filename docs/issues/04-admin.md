# 04 · Organizer admin

This screen is visible only to organizers.

- **Camp:** name, camp days (3–5, with dates), registration wave dates for U15, U18 and O18.
- **Activities:** name, short description, one logo image (upload to R2, replace, delete).
- **Offerings** (edited inside the activity form as "terminy"): days (one or more), gender restriction, age bracket restriction, capacity (empty = unlimited), high demand flag.
- **Participants:** list, edit gender and age bracket, remove, make someone an organizer.
